# Security Policy

## Reporting a vulnerability

Please report suspected vulnerabilities privately to:

deepscreen.online@outlook.com

Include the affected URL or repository path, a minimal reproduction, security impact, and relevant request/response details. Do not include passwords, access tokens, payment credentials, or other users' personal data.

Do not publicly disclose an unpatched vulnerability.

## Testing boundaries

Only test accounts, systems, and data you own or are explicitly authorized to assess. Do not perform denial-of-service, destructive database actions, credential theft, phishing, social engineering, or attacks on third-party providers.

## Scope

Security reports for DeepScreen include authentication and authorization, server functions and APIs, payment flows, server-side request handling, input validation, XSS/CSRF/SSRF, sensitive-data exposure, database access controls, dependency/supply-chain issues, and other application security defects.

Automated scanner noise without a reproducible security impact may be closed as informational.
